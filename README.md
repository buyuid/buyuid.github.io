# Buhari Yunusa Idris — Academic Personal Website

## Files
- `index.html` — complete responsive website
- `profile.jpg` — profile photograph

## Publish with GitHub Pages
1. Create a GitHub account and sign in.
2. Create a new repository (for example: `buhari-yunusa-idris`).
3. Upload `index.html` and `profile.jpg` to the repository's main branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the main branch and `/ (root)`, then save.
7. GitHub will provide the public website address.

The website uses no build tools or frameworks, so it can be hosted directly from the repository.
